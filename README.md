# devops-lean — подготовка к техническим собеседованиям

Здесь хранятся конспекты по крупным техническим темам. Один файл — одна тема.

## Темы

- [Linux](./linux.md) — процессы и ресурсы, `top`, диагностика падений, файловые системы и производительность `ls`.

## Как пользоваться

Основная книга: Брайан Уорд, «Внутреннее устройство Linux», 3-е издание. В конспекте указываем соответствующие разделы книги. Пока нет файла русского издания, используем проверенную нумерацию оригинала без выдуманных страниц и цитат.

Материал пишем по схеме: понятное объяснение → пример → команда → разбор результата → короткий ответ на собеседовании. Новый термин объясняем при первом использовании. Сведения из документации утилит отмечаем отдельно от привязок к книге.

Читайте раздел, повторяйте команды в тестовой Linux-среде и проговаривайте вслух: что измеряет команда, как читать результат и какие есть ограничения. В конце каждого раздела — короткие вопросы для самопроверки.
